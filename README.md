# فواتير الماء والكهرباء — مشروع Android v2

مشروع أندرويد جاهز للرفع إلى GitHub وبنائه باستخدام GitHub Actions.

## المزايا المنفذة
- واجهة عربية مع نمط داكن، سبعة مستفيدين وسجل القراءات المبدئي، وإضافة مستفيدين جدد.
- حساب الفواتير وتوزيع الكهرباء والماء، وفواصل الآلاف.
- قفل القراءات السابقة، وحفظ بيانات المستفيدين ومسودة الفاتورة محليًا تلقائيًا.
- استيراد جهة اتصال من منتقي جهات اتصال أندرويد دون طلب صلاحية قراءة كل جهات الاتصال.
- نسخ احتياطي JSON عبر منتقي ملفات أندرويد؛ يمكن اختيار Google Drive كموقع للحفظ عند ظهوره.
- استعادة JSON من منتقي الملفات، ورسائل واتساب وSMS فردية وجماعية مع معاينة وإرسال يدوي.

## لم ينفذ بعد
- استيراد وتصدير ملفات Excel بصيغة XLSX؛ لا تستخدم JSON بامتداد XLSX.
- النسخ المجدول التلقائي إلى Google Drive؛ الحفظ إلى Drive يدوي عبر منتقي الملفات.
- لا توجد نتائج اختبار APK فعلية في هذه البيئة؛ نجاح البناء والتشغيل يحتاجان اختبار GitHub Actions وهاتف أندرويد.

## البناء
ارفع محتويات هذا المجلد إلى مستودع GitHub (الجذر)، ثم افتح Actions > Build Android APK > Run workflow.
يمكن تنزيل APK من Artifacts بعد نجاح البناء.

## تنبيه التحديث
معرّف التطبيق `com.bills.meter`. نسخة debug الجديدة قد تحمل توقيعًا مختلفًا عن APK القديم، فلا يمكن ضمان التحديث فوقه. **لا تحذف التطبيق القديم أو بياناته** قبل استخراج نسخة احتياطية والتحقق من إمكان الاستعادة.

لضمان تحديثات متتابعة في المستقبل يجب توقيع إصدارات release بنفس مفتاح توقيع محفوظ وآمن، وليس الاعتماد على مفاتيح debug المؤقتة.
