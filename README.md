# تطبيق فواتير الماء والكهرباء — الريال اليمني
واجهة عربية تعمل محليًا، مع إدخال قراءات 7 مستفيدين وتوزيع الماء والكهرباء حسب فروق العدادات، سجل فواتير، مشاركة واتساب وSMS، نسخ احتياطي واستعادة.

## بناء APK
1. افتح المشروع في Android Studio (JDK 17, SDK 35) واختر Build > Build APK(s).
2. أو ارفع ملفات المشروع إلى مستودع GitHub ثم افتح Actions > Build Android APK > Run workflow، وبعد اكتمال المهمة نزّل ملف YemenBills-APK من Artifacts.

ملف التثبيت الناتج هو app-debug.apk. لم يتم إنشاء أو اختبار APK في هذه البيئة.

## الحساب
تكلفة الكهرباء = (قراءة الكهرباء الحالية - السابقة) × التعرفة. إجمالي فروق العدادات = مجموع (قراءة المستفيد الحالية - السابقة) للقراءات غير الصفرية. نصيب كل مستفيد = (فرق قراءته ÷ مجموع الفروق) × تكلفة الماء أو الكهرباء. العملة ريال يمني.

ملاحظة: تمت استعادة بيانات القراءات والأسماء وأرقام العدادات من ملف الإكسل المرفق. السجل يبدأ بقراءات أساس صفرية. تُحفظ بيانات التطبيق على الجهاز ويجب تصدير نسخة احتياطية قبل حذفه.
